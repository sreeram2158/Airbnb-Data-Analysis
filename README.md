# Airbnb-Data-Analysis
Airbnb Data Analysis and Exploratory Data Analysis using Python

# Project Overview

This project performs Exploratory Data Analysis (EDA) on Airbnb listing data using Python.

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

# Dataset

The Airbnb dataset is provided as a compressed ZIP file because the original CSV is too large for direct GitHub upload.

Download the ZIP file, extract it, and place the CSV file in the project folder before running "Airbnb_EDA.ipynb".

The dataset contains Airbnb listing information including:

- Price
- Room type
- Neighbourhood
- Reviews
- Availability
- Host information

# Data Cleaning

The project includes:
- Checking missing values
- Handling missing values
- Converting the "last review" column to datetime
- Removing unnecessary columns
- Converting price and service fee to numeric values
- Removing duplicate records

# Exploratory Data Analysis

The following analyses and visualizations were performed:
- Distribution of listing prices
- Room type distribution
- Listings by neighbourhood group
- Price vs. room type
- Number of reviews over time

# Conclusion

This project explores Airbnb listing data and provides insights into pricing, room types, neighbourhoods, and reviews.

# Key Insights

The Airbnb dataset contains over 100K listings with substantial variation in prices and accommodation types. Listings are distributed across multiple neighbourhood groups, and room type shows differences in pricing. The dataset contained significant missing values and duplicate records, which were handled during preprocessing. Review activity was also analyzed over time to identify changes in listing engagement.
